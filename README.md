# Leitor de Código de Barras

Página única (`index.html`) que lê códigos de barras pela câmera do celular e decodifica a chave de acesso de NF-e/NFC-e (44 dígitos): UF, emissão, CNPJ, modelo, série, número e validação do dígito verificador. Também reconhece EAN/UPC e linha digitável de boleto.

Requer HTTPS para acessar a câmera (GitHub Pages já serve em HTTPS).
